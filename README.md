# gear-editors

Free, browser-based editors and librarians for hardware synths and music gear. No install and no account: plug in, open the page and tweak.

**Open them here:** https://capmisteri.github.io/gear-editors/

They use Web MIDI, so use Chrome, Edge, Brave or Opera on desktop, connect your instrument before opening an editor, and allow MIDI (including SysEx) access when the browser asks.

If one of them saved you some menu-diving, you can support the project on [Ko-fi](https://ko-fi.com/capmisteri).
